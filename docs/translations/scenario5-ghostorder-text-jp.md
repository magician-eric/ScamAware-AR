# 情境五：ゴースト注文（偽購入者詐欺）— フロントエンド中国語テキスト完全抽出・日本語版

対話、ボタン、見出し、注釈などをファイル単位で分類し、逐語訳ではなく自然な日本語として意味が正しく伝わるように翻訳しています。純粋なコードコメントは含みません。`{{ }}` / `${...}` はアプリが動的に挿入する内容（商品名、金額、エラーコードなど）を示し、固定文言ではありません。

**ブランド名について：** このシナリオに登場する架空のプラットフォームは、既存の翻訳慣例（黑皮購物→「HappyPick Shopping」、黑皮通→「HAPPY EXPRESS」）に倣い、音訳ではなく英語ブランド名をそのまま使用しています。MyDonDon 買東東（マーケットプレイス／SNSアプリ）→ **MyDonDon**（翻訳せず、表記も変更しない）、速取便（詐欺の鍵となる配送・決済プラットフォーム）→ **SwiftPick**。架空のURL（`suqubian.tw`、`service-suqubian-tw.com`）は他のアプリ内URLと同様、変更せずそのまま表記しています。`NT$` の金額表記および `165` 番（詐欺相談ホットライン）も、本プロジェクトの既存の慣例に従いそのまま使用しています。

## Quiz.jsx（Q1〜Q4・詐欺対策クイズ）

**第1問**
- 購入者が「注文できない」と言い、サポートへのリンクを送ってきました。あなたはどうしますか？
- A：プラットフォームの公式サイトから自分でサポートを探す
- B：購入者から送られてきたサポートアカウントに直接連絡する
- 解説：サポートへの連絡先は、必ず公式サイトや公式アプリから取得しましょう。見知らぬ人が送ってきたリンクは使わないでください。

**第2問**
- プラットフォームのサポートが、受取機能を有効にするためにお金の振込を求めてきました。これは合理的だと思いますか？
- A：合理的。完了後にシステムが返金してくれるはず
- B：不合理。お金を受け取るのに先に振り込む必要はない
- 解説：正規のプラットフォームが、受取機能の認証のために出品者へ振込やカードレスATM出金、ポイント購入を求めることはありません。

**第3問**
- 偽サポートは、認証に協力しないと購入者のアカウントも凍結されると言っています。あなたはどうしますか？
- A：取引を中止し、公式または165番に確認する
- B：購入者に迷惑をかけないよう、すぐに応じる
- 解説：詐欺グループは責任感や時間的プレッシャーを利用し、被害者が確認する余裕を与えないようにすることがよくあります。

**第4問**
- 次のうち、最も重要な判断基準はどれですか？
- A：商品を売ってお金を受け取るのに、先に払う必要はない
- B：サポートがビデオ通話に応じてくれれば信用できる
- 解説：ビデオ通話、制服、身分証、それらしい話し方はすべて偽装できるため、本人確認の証拠にはなりません。
