# 1. 系統介紹

**CIBAR 反詐 AR 體驗**是一套沉浸式的反詐騙教育體驗。

參觀者戴上 AR 眼鏡（或直接使用手機畫面）後，用鏡頭對準展場的辨識圖片，系統會自動判斷那是哪一種詐騙，並把參觀者帶進對應的模擬情境。情境裡會出現擬真的社群貼文、聊天視窗、投資平台、購物網站或警方來電，參觀者要在關鍵時刻做出選擇。

一次完整的體驗大約是這樣：

```
掃描辨識圖片 → 進入詐騙情境 → 過程中做選擇 → 出現結局（受騙／成功反詐）
→ 詐騙疑點分析 → 反詐小測驗 → 回到掃描畫面，換下一位
```

**共有五種詐騙情境**：假投資、假交友、假檢警、假賣家、假買家。
**共有三種語言**：中文、English、日本語。
**操作方式**：以左揮／右揮兩種手勢為主，觸控螢幕為備援。

體驗的目的不是「答對題目」，而是讓參觀者親身感受詐騙的話術怎麼一步步推進，以及在哪一步應該停下來。**選到受騙的結局並不是失敗**——那是這套系統最重要的教材，後面的疑點分析會告訴他剛才錯過了哪些警訊。

# 2. 設備介紹

| 設備 | 用途 | 現場注意 |
| --- | --- | --- |
| Android 手機（展示機） | 執行「反詐AR體驗」App，是整套體驗的主機 | 開場前務必充飽電；建議準備行動電源 |
| AR 眼鏡 | 提供參觀者的畫面、提供辨識用的相機、辨識左揮／右揮手勢 | 用傳輸線連接手機，接上後要留意授權提示 |
| 展場辨識圖片（5 張） | 每一張對應一個詐騙情境，是進入體驗的入口 | 保持乾淨平整，避免反光、折痕與遮擋 |

| 擦拭布 | 清潔眼鏡鏡片與手機鏡頭 | 鏡頭有指紋會明顯降低辨識率 |

> 手機、眼鏡、圖片三者缺一不可。眼鏡沒接上時，體驗仍可用手機畫面與觸控完成，但就不是完整的 AR 體驗了。

# 3. App 版本說明（重要：只有一個版本）

**現在只有一支 App，桌面名稱就是「反詐AR體驗」。**

過去曾經有「線上版」與「離線版」兩支 App，需要現場判斷該開哪一支。**那個做法已經取消了。**如果你手上的舊教材、舊簡報或舊 SOP 還寫著「沒有網路請開離線版」，請以本手冊為準。

現在的規則很單純：

| 你想知道的事 | 答案 |
| --- | --- |
| 桌面上要點哪一個？ | **反詐AR體驗**，只有這一個 |
| 現場沒有網路可以用嗎？ | **可以，而且是完全可以。**整個體驗的內容都存在手機裡 |
| 什麼時候需要網路？ | 只有「更新體驗內容」時。體驗本身不需要 |
| 沒更新會怎樣？ | 不會怎樣，照舊使用目前手機上的版本 |
| 更新什麼時候生效？ | 系統會在有網路時自己在背景下載，**下一次重新開啟 App 才會換成新版**，不會在體驗進行到一半時突然改變 |

> **給場館的建議**：開館前若有網路，讓 App 開著幾分鐘，讓它有機會把新版抓下來；當天最後一次關閉、隔天早上開機時就會是新版。**體驗進行中不需要、也不應該特別去連網路。**

# 4. 系統啟動流程

請照順序操作。

1. **開啟 Android 展示機**，確認電量充足。
2. **連接 AR 眼鏡**。若手機跳出 USB 裝置使用授權的詢問，請允許。
3. **點開桌面上的「反詐AR體驗」**。
4. **等待開場動畫**。開啟後會先播放約 **7 秒**的開場動畫（中文標題先出現，接著英文與日文），這段期間畫面**不接受點擊**，屬正常現象。
   - 教育訓練或反覆測試時想略過：**在畫面右上角，1.5 秒內連續點 3 下**，動畫會立刻結束。這是給工作人員用的捷徑，**不要教給參觀者**。
5. **進入語言選擇畫面**（畫面上有中文／English／日本語三顆按鈕）。
6. **【工作人員先做】確認定位設定**：點畫面**右上角的齒輪圖示** → 進入工作人員模式 → 確認或設定所在地 → 儲存並鎖定 → 開始玩家模式。詳見第 6 章與第 11 章。
   - **這一步在把裝置交給參觀者之前完成。**參觀者拿到之後就沒有機會再改了。
7. **把裝置交給參觀者，請他選擇語言。**
8. **手勢教學**：選完語言會自動進入手勢教學，要先向左揮一次、再向右揮一次才能通過。詳見第 7 章。
9. **自動進入 AR 掃描畫面**（手勢教學完成後約 1 秒自動跳，不必再按任何按鈕）。
10. **請參觀者把鏡頭對準展場的辨識圖片**，辨識成功會直接進入對應情境。

> **注意順序**：定位是在「語言選擇畫面」上做的，不是在體驗中做的。體驗過程中系統**不會**再要求任何人定位。

# 5. 語言選擇

語言選擇畫面上有三顆按鈕：

- **🇹🇼 中文**
- **🇺🇸 English**
- **🇯🇵 日本語**

點下去就完成選擇，並直接進入手勢教學。之後整個體驗——情境內容、旁白、結局說明、疑點分析、反詐小測驗——都會使用這個語言。

### 選錯語言怎麼辦？

**還在手勢教學或 AR 掃描畫面時**：使用 AR 眼鏡的返回鍵，或請工作人員把畫面帶回語言選擇畫面，重新點一次正確的語言即可。重新選語言之後，**手勢教學會從頭再做一次**（先左揮、再右揮），這是正常的。

**已經進入情境了**：建議讓這位參觀者把目前這一輪走完（或由工作人員從工作人員模式回到首頁），再重新選語言開始。中途切換語言不是設計中的操作。

> **提醒**：工作人員模式的畫面固定是中文，不會跟著參觀者選的語言改變，這是刻意的設計，不是故障。

# 6. 定位設定

## 為什麼一定要先確認定位

五個情境中的「**假檢警詐騙**」會使用**你現在所在的縣市**來產生畫面上的內容：

- 假來電顯示的**警察局與分局**名稱
- 假案件網站上的**地檢署、地方法院**
- 假來電的**市話號碼區碼**
- 承辦員警所屬的**派出所**

定位正確，參觀者看到的就是「自己家附近的分局」，衝擊感完全不同；定位錯誤，畫面上就會出現別的縣市的機關名稱，教育效果會打折，也容易被在地民眾質疑。

**所以：每一場開始前，都要確認一次定位。**

## 怎麼設定

從語言選擇畫面**右上角的齒輪圖示**進入（若齒輪按不到，也可以**長按畫面左上角的標誌區域約 5 秒**，這是備用入口）。

進去之後畫面最上方是「**目前所在地設定**」，下面有這幾顆按鈕：

| 按鈕 | 什麼時候用 | 會發生什麼 |
| --- | --- | --- |
| **重新取得目前位置** | 現場可以定位時，優先用這個 | 系統嘗試取得目前位置，成功後會把對應的縣市、警察局、地檢署、法院與區碼帶出來 |
| **手動修正所在地** | 定位失敗、沒有網路，或定位結果不正確時 | 出現「縣市」與「行政區」兩個下拉選單，選好後按「套用」 |
| **儲存並鎖定** | 確認畫面上的資料正確之後 | 把設定存進手機並鎖定，之後參觀者無法更改 |
| **清除所在地快取** | 換場館、換縣市，想重設時 | 清掉目前設定，回到「尚未設定」 |
| **返回首頁** | 設定完想離開時 | 回到語言選擇畫面 |

按下「儲存並鎖定」後，會出現一張確認卡片，列出**使用地區、對應警察機關、對應檢察機關、對應法院、地區電話區碼、目前日期時間**。請看過一遍再按「**開始玩家模式**」。

## 沒有網路的時候怎麼辦

**照樣可以設定，用「手動修正所在地」就好。**縣市與行政區的清單、以及對應的警察局、地檢署、法院、區碼資料，全部都存在手機裡，不需要網路。

如果按「重新取得目前位置」失敗，畫面會直接告訴你原因與建議做法，例如：

- 「目前無法取得精確位置，請移至靠近窗戶的位置後重試，或使用手動設定。」
- 「定位權限遭拒絕。請開啟定位權限，或使用手動設定。」
- 「定位逾時，請重試或使用手動設定。」
- 「目前無網路連線……可使用本機離線比對或手動設定。」

**看到任何一種，都改用手動設定即可，不影響體驗。**

## 定位錯誤怎麼修改

隨時可以回到工作人員模式，按「**手動修正所在地**」改成正確的縣市與行政區，再按「**儲存並鎖定**」。**下一位參觀者**就會看到修正後的機關名稱。

## 沒有設定會怎樣

系統會使用預設值：**臺北市信義區**（信義分局、臺灣臺北地方檢察署、臺灣臺北地方法院、區碼 02）。體驗不會卡住，但在臺北以外的場館，畫面上會出現臺北的機關名稱。**所以還是要設。**

## 有些行政區會出現提示

少數行政區（例如臺北市中正區、臺北市文山區、新北市板橋區、高雄市三民區）實際上跨兩個分局的轄區。遇到這些地方，畫面會顯示提示，表示系統暫時以其中一個分局為準。**這是已知且刻意標示的限制，不是故障**，不需要處理；若現場需要指定另一個分局，請改用手動設定選擇鄰近的行政區。

# 7. 手勢操作教學

這是現場最需要口頭引導的一段，請務必熟練。

## 兩個手勢，就這兩個

| 手勢 | 動作說明 | 給參觀者的口令 |
| --- | --- | --- |
| **左揮** | 手掌張開，**慢慢**向左揮動 | 「請把手掌張開，慢慢向左揮。」 |
| **右揮** | 手掌張開，**慢慢**向右揮動 | 「請把手掌張開，慢慢向右揮。」 |

**沒有上揮、下揮，也沒有比手勢或握拳。**整套體驗只用這兩個動作。

## 最常見的失敗原因：揮太快

請在教學時就提醒：

> 「**不要揮太快。**揮太快系統會來不及看到，就沒有反應。像在跟人打招呼那樣，慢慢揮過去就好。」

其他常見狀況：手離眼鏡太近、只動手指沒有動手掌、揮到一半就縮回來。都提醒「**張開手掌、慢慢地、揮完整一次**」即可。

## 選項怎麼對應

這是要教給參觀者的核心規則，很簡單：

| 畫面上的狀況 | 怎麼做 |
| --- | --- |
| **有兩個選項** | **左揮 = 選左邊那個；右揮 = 選右邊那個** |
| **只有一個「繼續／確認」的按鈕** | **右揮**（此時左揮沒有作用） |
| **畫面正在自動播放，沒有選項** | 什麼都不用做，等它播完 |

## 手勢教學畫面

選完語言後會自動進入手勢教學，畫面上有左右兩個面板：

1. 先出現「**向左揮**」的提示 —— 這時候**只有左揮有效**，右揮完全沒有反應（這是刻意的，不是壞掉）。
2. 完成後換成「**向右揮**」 —— 這時候只有右揮有效。
3. 兩步都完成後顯示「**手勢教學完成**」，約 1 秒後自動進入 AR 掃描畫面。

**這一關沒有「跳過」按鈕，一定要真的做出兩個手勢才能過。**

## 玩家一直不會操作的時候

請照這個順序處理：

1. **先口頭提醒**：「請將手掌張開，慢慢向左揮（或向右揮）。」
2. **示範一次**給他看。
3. 還是不行 → **請他改用觸控**。手勢教學畫面上的兩個面板本身就可以直接**用手指點**，點左邊的面板等於左揮一次。
4. 進入情境後同樣可以全程用觸控：**畫面上的選項按鈕都可以直接點**。

> **觸控是正式的備援方式，不是作弊。**行動不便、手部無力、時間有限的參觀者，直接用觸控完成整場體驗完全沒問題。

# 8. AR 圖片辨識操作

## 怎麼帶參觀者掃描

AR 掃描畫面上有一個相機取景框，框裡是即時影像，下面寫著「**將鏡頭對準可疑的圖片或物件**」。

請這樣引導：

1. **請參觀者面向辨識圖片**，讓圖片出現在取景框裡。
2. **整張圖片要完整出現在畫面中**，不要只拍到一半。
3. **不要用手或身體遮住圖片的主要圖案。**
4. **保持適當距離**：大約一個手臂到一步半的距離，圖片在畫面中佔一半以上最好。
5. **拿穩、停一下。**不要一直左右晃動，讓鏡頭有時間看清楚。
6. **辨識成功時，裝置會震動一下，並直接進入對應的情境**——沒有確認按鈕、沒有倒數，這是正常的。

## 五張圖片對應哪一個情境

| 圖片 | 進入的情境 | 詐騙類型 |
| --- | --- | --- |
| 圖片 1 | 財富陷阱 | 假投資詐騙 |
| 圖片 2 | 戀愛劇本 | 假交友詐騙 |
| 圖片 3 | 權威陷阱 | 假檢警詐騙 |
| 圖片 4 | 黑箱包裹 | 假賣家騙買家 |
| 圖片 5 | 幽靈訂單 | 假買家騙賣家 |

> 請把展場圖片依這個編號擺放並貼上標示，工作人員才能一眼確認參觀者現在要去哪一個情境。

## 辨識不到的時候

按掃描畫面下方的「**沒有辨識圖片？手動選擇情境**」，會進入五格情境選單，直接點選要體驗的情境即可。**手動選擇進入的體驗跟掃描進入完全一樣**，不會少任何內容。

排除方式請見第 12 章。

# 9. 五個情境操作說明

以下是給工作人員看的操作流程，不是劇本全文。每個情境的長度大約 8～15 分鐘，視參觀者閱讀速度而定。

**五個情境的結尾格式完全相同**：

```
結局（詐騙成立／成功反詐） → 詐騙疑點分析 → 反詐小測驗 → 返回掃描
```

---

## 情境 01｜財富陷阱（假投資詐騙）

**體驗內容**
參觀者在社群平台看到「AI 智慧選股」的投資廣告，看完老師的招生影片後加入 LINE，被助理帶進 VIP 群組，群裡都是獲利截圖。接著到陌生投資平台註冊、投入本金，帳面一路獲利；但真的要提領時，平台說要先繳一筆保證金。

**玩家主要操作**

- 看社群廣告貼文（留言區會自動輪播）→ 點進招生影片
- 招生影片會自動播放，**播完才進入下一步**
- LINE 一對一對話：出現**二選一**（「我想直接跟老師操作」／「我想先自己試試看」）
- VIP 群組：訊息**逐則自動播放**，播完才出現「前往註冊平台」
- 投資平台：完成註冊 → 確認投資 → 看持股 → 看獲利 → 申請提領
- **關鍵決定**：出金失敗頁要求先付保證金 NT$30,000 →「確認支付」或「稍後處理」

**工作人員注意事項**

- **需要等待的畫面**：招生影片（整段）、LINE 對話（每則之間有停頓）、**VIP 群組約 25 秒**。這幾段沒有選項是正常的，請提醒參觀者「這裡先看，等一下才要選」。
- **VIP 群組是最容易被誤會當機的地方**，因為它會自己播很久。請預先說明。
- 影片播放中若上方浮出風險提示，那是系統的教學提示，**不會暫停影片**，過幾秒會自己縮成小標籤。
- **兩個結局都要能講**：選「確認支付」是**詐騙成立**；選「稍後處理」是**成功反詐**。選錯的那一位不必重來，疑點分析會補齊觀念。

**情境結束**
結局頁 → 「查看詐騙疑點分析」（列出六個疑點）→「進行反詐小測驗」→ 作答 → 「返回掃描」。

## 情境 02｜戀愛劇本（假交友詐騙）

**體驗內容**
參觀者在交友軟體上跟一位對象配對，聊天、加 LINE、培養感情，對方分享生活與未來計畫；等到信任建立之後，話題轉向「額外收入」，並被引導到一個投資平台入金。最後要提領時，平台要求再付一筆「安全驗證金」。

**玩家主要操作**

- 交友軟體滑卡：**左揮＝略過、右揮＝喜歡**（會先滑過兩張過場人物卡，才輪到主線對象）
- 站內聊天：多輪**二選一**回覆，最後決定要不要加 LINE
- LINE 養成期對話：多輪二選一；中途有**自拍影片**與**照片**可以點開看
- 在 LINE 與投資平台之間往返多次（註冊、啟用策略、入金、看獲利、申請提領）
- **關鍵決定**：提領失敗後對方要求再付 NT$30,000 驗證金 →「我還是覺得不對勁」／「好，我再試最後一次」

**工作人員注意事項**

- 這是**最長**的一個情境，對話量最大。時間緊湊時建議改推薦情境 04 或 05。
- **從投資平台回到 LINE，一定要由玩家自己按畫面底部的「返回 LINE 對話」**，平台頁面**不會自己跳回去**。停在平台頁看起來像卡住，其實只是在等人按。這是最常見的誤會，請先講。
- 平台頁面上方的其他圖示、快捷列與底部分頁是**故意不能按的裝飾**，不是失效。
- 第一次入金**刻意不會跳出強制警示**，這是設計；第二次要驗證金時才會攔下來讓玩家決定。
- 影片與照片點開後看完會自動關閉並繼續對話。

**情境結束**
結局頁（「感情是假的，損失是真的」或成功停手）→ 詐騙疑點分析（五個揭露）→ 反詐小測驗 → 返回掃描。

## 情境 03｜權威陷阱（假檢警詐騙）

**體驗內容**
參觀者接到一通自稱警方的來電，說他的身分資料涉及詐欺洗錢案。對方要求加 LINE、看「案件網站」與公文，接著假檢察官來電施壓，最後要求把存款轉入「監管帳戶」自證清白。

**這是唯一會用到定位資料的情境，開場前務必先確認定位。**

**玩家主要操作**

- 模擬手機桌面 → **自動出現陌生來電** → 接聽（也可以拒接，對方會再打來）
- 警方通話：有**語音與同步字幕**；中途出現**二選一**（是否曾申辦門號／資料是否外流）
- 加 LINE → 看案件說明與案件卡 → 二選一（是否先問家人或撥 165）
- 進入假案件網站 → **逐一點開四份假公文**
- 假檢察官來電 → 二選一（名下有幾個帳戶）→ 承辦員警回撥 → LINE 資金監管指示
- 模擬網銀：登入 → 選擇轉帳金額（部分／全部）→ 轉帳確認
- **關鍵決定**：「照對方說的，按下確認轉帳」／「先停下來，掛掉電話，自己撥 165 查證」

**工作人員注意事項**

- **有語音**。展場吵雜時請準備耳機，否則教學效果會大幅下降。
- **通話畫面要等**，語音與字幕是同步播放的，中途沒有選項是正常的。**目前沒有加速播放的功能**，請預留時間。
- 通話中同時會收到 LINE 訊息，兩邊**不會**互相中斷，這是設計。
- 選「撥打 165 查證」之後**會直接顯示成功反詐的結局**，畫面上不會播一段 165 通話。**這不是漏掉了**——拿起電話撥 165 這個決定本身就是正確答案。
- 請留意畫面上的機關名稱是不是你設定的縣市；如果不是，代表定位設定沒做或做錯了。
- 每一輪的承辦員警姓名、派出所、案件編號都會重新產生，**同一輪內不會變**。

**情境結束**
結局頁 → 詐騙疑點分析（八個手法標籤：假警察來電、假檢察官施壓、LINE 私下聯絡、偽造案件網站、偽造監管帳戶、要求保密、製造時間壓力、引導銀行轉帳）→ 反詐小測驗 → 返回掃描。

## 情境 04｜黑箱包裹（假賣家騙買家）

**體驗內容**
參觀者在購物平台買下一件熱門商品，收到的實物卻和商品頁完全不符。接著開始申請退貨，賣家一路推託、退款一直拖延，最後賣家失聯，平台也表示無法處理平台外的款項。

**玩家主要操作**

- 模擬手機桌面 → 開啟「黑皮購物」→ 選商品（掃地機器人或福袋，兩條路線流程一樣）
- 商品頁 →（可先詢問賣家）→ 直接購買 → 確認付款
- 訂單頁 → 按「**查看最新物流**」讓包裹一站一站送達 → 「拆開包裹」
- 開箱：拆外箱 → 拿出內容物 → 看「商品頁宣稱 vs 實際收到」對照
- 與賣家爭議 → 申請退貨 → 寄回商品 → 追蹤退貨物流 → 催退款
- 退款中心 → 聯絡平台客服 → **關鍵決定**：「繼續要求平台負責」／「聯絡 165 報案」

**工作人員注意事項**

- 爭議對話中如果參觀者選了「**算了，不想那麼麻煩**」→「**先完成訂單好了**」，畫面會回到訂單頁並標示訂單已完成。**這不是結束**：請他按「**查看售後進度**」，就會接到黑皮客服，客服會說「系統顯示您先前已確認完成訂單……仍可以建立爭議案件」，之後同樣走到結局與小測驗。這條路線比較短，也是很好的教材——放棄爭取的人，最後還是要面對同一個結果。
- 「**查看最新物流**」要按好幾次，每按一次前進一個物流狀態，按鈕短暫變成「物流更新中…」不能按是正常的，等一下就好。
- 退貨物流追蹤也是同樣的「按一下、等一下」節奏。
- 退款催促階段畫面上會自動出現「五天後」「七天後」的時間推進，那是劇情，不是當機。
- **兩個結局都要能講**：「繼續要求平台負責」→ 詐騙成立；「聯絡 165 報案」→ 成功反詐。

**情境結束**
結局頁 → 詐騙疑點分析 → 反詐小測驗 → 返回掃描。

## 情境 05｜幽靈訂單（假買家騙賣家）

**體驗內容**
參觀者這次是**賣家**。刊登二手商品後，一位親切的買家出現，說自己習慣用另一個「交易網站」，要求賣家去那裡開一個專屬賣場。買家在那個網站上顯示「已付款」，但官方平台完全沒有這筆訂單。商品寄出後，錢從來沒有進來，買家也消失了。

**玩家主要操作**

- 模擬手機桌面 → 開啟「買東東」→ 我要賣・刊登商品 → 選一件商品刊登
- 收到買家訊息 → 進入聊天，多輪**二選一**
- **關鍵段落**：買家要求到外部網站「SafeDeal」建立專屬賣場
  - 即使選擇「我先確認一下官方交易流程」，看完安全提醒後**劇情仍會回到建立賣場**（這是刻意的：話術會繞回來）
- 在外部網站建立賣場 → 回聊天 → 買家貼出「已付款」畫面
- 回買東東查訂單 → **查無此筆訂單**
- **關鍵決定**：要不要相信對方、先把商品寄出
- 寄出後 → 商品送達 → 詢問款項 → 「此帳號已不存在」→ 外部網站也連不上

**工作人員注意事項**

- 這個情境**最短、最好懂**，適合時間有限或年長的參觀者。
- 聊天訊息是**逐則自動出現**的，選項要等對方講完才會跳出來。
- 請提醒參觀者注意一個關鍵：**「買東東沒有這筆訂單」**。這是全場最重要的警訊。
- 外部網站的畫面做得很像正規平台，**這正是教材重點**，可以在結束後特別點出來。

**情境結束**
結局頁（「這是一筆幽靈訂單」）→ 詐騙疑點分析（買家要求離開原平台／外部網站顯示假的付款成功／官方平台其實沒有訂單／真的商品卻被寄出去了）→ 反詐小測驗 → 返回掃描。

# 11. 工作人員模式

## 怎麼進入

在**語言選擇畫面**：

- **正式入口**：點**右上角的齒輪圖示**。
- **備用入口**：**長按左上角的標誌區域約 5 秒**（沒有進度提示，按住就對了）。

> 這兩個入口刻意做得不顯眼，**請不要在參觀者面前示範**，也不要寫在對外的說明牌上。

## 裡面有哪些功能

工作人員模式**固定使用中文**，共兩個區塊：

### 一、目前所在地設定

| 功能 | 用途 |
| --- | --- |
| 重新取得目前位置 | 自動定位 |
| 手動修正所在地 | 用縣市／行政區下拉選單指定（沒有網路時用這個） |
| 儲存並鎖定 | 存檔並鎖定，之後參觀者不能改 |
| 清除所在地快取 | 重設為「尚未設定」 |
| 返回首頁 | 回到語言選擇畫面 |

存檔後會出現確認卡片，按「**開始玩家模式**」離開設定、把裝置交給參觀者。

### 二、系統版本與更新

這一區是給需要回報狀況或確認版本時使用的。上半部顯示裝置類型與目前的版本資訊（APK 版本、體驗內容版本、最後檢查更新的時間等），下半部是操作按鈕：

| 按鈕 | 什麼時候出現／使用 |
| --- | --- |
| **檢查更新** | 隨時可按。會實際去看看有沒有新版 |
| **下載更新** | 確定有新版時才會出現 |
| **重新啟動並套用更新** | 新版下載並檢查完成後才會出現。**按下去 App 會重新啟動**，所以**不要在有人正在體驗時按** |

畫面上的「更新狀態」會用中文說明目前情形（例如：尚未檢查／已是最新版本／發現新版／正在下載／更新已準備完成，等待下次啟動／無網路／更新失敗）。**更新失敗不會影響體驗**，目前的版本照常可以使用，稍後再按一次檢查更新即可。

## 哪些功能正式展場可以使用

**全部都可以**，但請遵守兩個原則：

1. **所在地設定**：每場開始前做一次，做完就好。
2. **系統版本與更新**：只在**沒有人正在體驗**時操作，特別是「重新啟動並套用更新」。

## 調整完怎麼回到體驗

按「**返回首頁**」（或存檔後按「**開始玩家模式**」），就會回到語言選擇畫面，可以直接把裝置交給下一位參觀者。

> **工作人員模式裡沒有「情境測試」「畫面捲動」「跳過劇情」之類的控制功能。**若你在舊資料上看到這些，那是已經移除的舊版本。現場要測試某一個情境，請用 AR 掃描畫面的「手動選擇情境」進入。

# 12. 常見問題與現場排除

> 以下每一項都只寫**現場人員可以自己做**的處理。如果照做仍無法解決，請記錄「哪一個畫面、按了什麼、看到什麼訊息」，回報維護窗口。

### App 沒有正常開啟／點了沒反應

1. 確認點的是「**反詐AR體驗**」。
2. 完全關閉 App（從最近使用的程式清單滑掉），再重新開啟。
3. 仍不行 → 重新啟動手機。
4. 開啟後前 7 秒是開場動畫，**這段時間點不動是正常的**，請先等它播完。

### AR 眼鏡沒有畫面

1. 檢查傳輸線兩端是否確實接好，換一條線試試。
2. 拔掉眼鏡再重新接上，注意手機上是否跳出授權提示，**要按允許**。
3. 完全關閉 App 再重開（眼鏡要在開 App **之前**接好）。
4. 確認眼鏡鏡片沒有被遮住、參觀者配戴位置正確。

### 相機沒有畫面（掃描畫面是黑的或顯示「無法使用相機」）

1. 先確認眼鏡已接好且已授權（見上一項）。
2. 完全關閉 App 再重開。
3. 手機設定中確認「反詐AR體驗」的**相機權限**已開啟。
4. **當下仍不行 → 按「沒有辨識圖片？手動選擇情境」讓體驗照常進行**，不要讓參觀者空等。

### 圖片一直辨識不到

1. **距離**：太近或太遠都不行，調整到圖片佔畫面一半以上。
2. **完整**：整張圖片要在框內，不要只拍到一部分。
3. **遮擋**：手、身體、其他參觀者不要擋到圖案。
4. **反光**：換角度避開燈光直射；必要時移動圖片位置或加遮光。
5. **穩定**：請參觀者拿穩、停 2～3 秒，不要一直晃。
6. **鏡頭髒污**：用擦拭布把鏡頭擦乾淨（很常見）。
7. **圖片本身**：確認沒有折痕、褪色、被水漬弄花。備品換上。
8. 以上都試過還是不行 → **改用「手動選擇情境」**。

### 手勢沒有反應

1. **先確認是不是揮太快**——這是第一名的原因。請示範慢速揮動。
2. 確認手掌**張開**，而且在眼鏡前方適當距離（不要貼太近）。
3. 確認畫面上**現在真的有選項**。自動播放中的畫面本來就不接受手勢。
4. 確認揮的方向正確：**只有一個「繼續」按鈕時要右揮**，左揮沒有作用。
5. 眼鏡重新接一次，或完全關閉 App 再重開。
6. 仍不行 → **請參觀者直接用手指點畫面**，體驗照常完成。

### 玩家揮手後選錯選項

- **選錯不需要重來。**五個情境的分支大多會回到同一條主線，選錯只是話術不同。
- **關鍵決定選到受騙結局**，也請照常走完：後面的**詐騙疑點分析**會把該注意的警訊全部列出來，這正是最有價值的一段。
- 真的需要重做（例如參觀者強烈要求），請由工作人員把畫面帶回 AR 掃描畫面，重新掃描該情境即可。

### 定位不正確（畫面上出現別的縣市的警局）

1. 進入工作人員模式 → 「**手動修正所在地**」→ 選正確的縣市與行政區 → 「套用」。
2. 按「**儲存並鎖定**」。
3. **下一位**參觀者就會看到正確的機關名稱（目前這一輪不會改變）。

### 現場沒有網路

- **體驗完全不受影響，照常進行。**
- 定位改用「**手動修正所在地**」。
- 「檢查更新」會顯示無網路，**忽略即可**。

### 影片沒有正常播放

1. 等 3～5 秒，可能還在載入。
2. 若畫面上出現「重新播放」或播放按鈕，點一下。
3. 確認手機沒有靜音、音量足夠（假檢警情境特別依賴聲音）。
4. 仍不行 → 完全關閉 App 再重開，重新進入該情境。

### 畫面卡住（好像沒有反應）

**先判斷是不是「其實正在自動播放」**——這是最常見的誤會：

- 情境 01 的 **VIP 群組**要跑約 25 秒
- 情境 03 的**通話畫面**要把語音講完
- 情境 04 的**物流更新**按鈕會短暫變成「物流更新中…」
- 情境 05 的**聊天訊息**會逐則出現
- 情境 02 從投資平台**要自己按「返回 LINE 對話」**才會回去

先等 30 秒。真的沒有任何變化再處理：

1. 用眼鏡的返回鍵回上一頁再進來。
2. 由工作人員回到 AR 掃描畫面，重新開始該情境。
3. 完全關閉 App 再重開。

### 無法返回 AR 掃描

- 正常路徑是：反詐小測驗畫面的「**返回掃描**」按鈕（這顆按鈕在作答前後都在，隨時可以按）。
- 中途想離開：用眼鏡返回鍵退回，或進工作人員模式按「返回首頁」，再從語言選擇往下走。

### 下一位玩家要開始體驗

1. 收回眼鏡，簡單清潔鏡片。
2. 確認畫面停在 **AR 掃描畫面**。
3. 口頭複習兩個手勢（左揮／右揮）。
4. 請他對準辨識圖片。
5. 需要換語言時，才回到語言選擇畫面重選。

請依序確認，全部打勾才開放參觀。

| # | 檢查項目 | 怎麼確認 | ☐ |

| 1 | **裝置** | 手機電量 ≧ 80%，或已接上行動電源 | ☐ |
| 2 | **AR 眼鏡** | 傳輸線接好，接上後已允許授權 | ☐ |
| 3 | **App** | 桌面點開「反詐AR體驗」，能正常播完開場動畫並進入語言選擇畫面 | ☐ |
| 4 | **版本** | 桌面只有「反詐AR體驗」這一支 App；若前一天有網路，可進工作人員模式按一次「檢查更新」 | ☐ |

| 6 | **定位** | 工作人員模式 → 確認縣市與分局是本場館所在地 → 儲存並鎖定 → 開始玩家模式 | ☐ |
| 7 | **圖片辨識** | 五張圖片**各掃一次**，確認都能正確進入對應情境 | ☐ |

| 11 | **返回掃描** | 任一情境的小測驗按「返回掃描」，能回到 AR 掃描畫面 | ☐ |

## 新人第一天的帶訓順序

1. 讀本手冊第 1、3、7 章（系統是什麼、只有一支 App、兩個手勢）。
2. 由資深人員示範一次完整體驗（建議用**情境 05 幽靈訂單**，最短）。
3. 新人自己走一次**情境 03 權威陷阱**（最長、最需要引導，也最能理解等待的節奏）。
4. 練習工作人員模式：進入 → 手動設定所在地 → 儲存並鎖定 → 開始玩家模式。
5. 練習口令：
   - 「請把手掌張開，**慢慢**向左揮。」
   - 「有兩個選項時，**左揮選左邊、右揮選右邊**。」
   - 「只有一個繼續的時候，**右揮**就好。」
   - 「不方便揮手的話，**直接點畫面**也可以。」
6. 跑一次第 13 章的開場檢查表。
7. 讀第 12 章常見問題，特別是「畫面卡住」與「手勢沒有反應」。

## 現場三個最常用的判斷

1. **參觀者沒反應** → 先問是不是揮太快 → 再問畫面上現在有沒有選項 → 最後改觸控。
2. **畫面像卡住** → 先等 30 秒（多半是在自動播放）→ 再處理。
3. **辨識不到** → 距離、完整、不遮擋、擦鏡頭 → 還是不行就用「手動選擇情境」，不要讓參觀者空等。
